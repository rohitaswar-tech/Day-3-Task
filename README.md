# Linux Basics - Day 3 Tasks

This repository contains the solutions for **Day 3 - Linux Basics Practical Tasks**, performed on an AWS EC2 instance (Amazon Linux / RHEL based) using commands like `head`, `tail`, `grep`, and `awk`.

## Tasks and Commands

### Task 1: First 5 lines of `/etc/group`
```bash
sudo sh -c 'head -n 5 /etc/group > /file2.txt'
cat /file2.txt
```

### Task 7: Count lines ending with `bash` in `/etc/passwd`
```bash
sudo sh -c "grep 'bash$' /etc/passwd | wc -l > /bash.txt"
cat /bash.txt
```

### Task 8: Count lines containing `nologin` in `/etc/passwd`
```bash
sudo sh -c "grep 'nologin' /etc/passwd | wc -l > /word.txt"
cat /word.txt
```

### Task 9: Search `systemd` in `/etc/passwd` and `/etc/group`
```bash
sudo sh -c "grep 'systemd' /etc/passwd /etc/group > /passgroup.txt"
cat /passgroup.txt
```

### Task 10: Search `root`, `rhel`, `systemd` in `/etc/passwd`
```bash
sudo sh -c "grep -E 'root|rhel|systemd' /etc/passwd > /search.txt"
cat /search.txt
```

### Task 11: Extract 5th column from `/etc/passwd`
```bash
sudo sh -c "awk -F: '{print \$5}' /etc/passwd > /file1.txt"
cat /file1.txt
```

### Task 12: Print columns 1 to 4 from `/etc/passwd`
```bash
sudo sh -c "awk -F: '{print \$1,\$2,\$3,\$4}' /etc/passwd > /file2.txt"
cat /file2.txt
```

### Task 13: Print columns 1 and 7 from `/etc/passwd`
```bash
sudo sh -c "awk -F: '{print \$1,\$7}' /etc/passwd > /file3.txt"
cat /file3.txt
```

### Task 14: Print column 1, sorted alphabetically
```bash
sudo sh -c "awk -F: '{print \$1}' /etc/passwd | sort > /file4.txt"
cat /file4.txt
```

### Task 15: Extract 3rd column (UID) from `/etc/passwd`
```bash
sudo sh -c "awk -F: '{print \$3}' /etc/passwd > /userid.txt"
cat /userid.txt
```

### Task 16: awk - print first and last columns
```bash
sudo sh -c "awk -F: '{print \$1,\$7}' /etc/passwd > /awkfile.txt"
cat /awkfile.txt
```

### Task 17: awk - print columns 1, 2, 3 with `-` as output delimiter
```bash
sudo sh -c "awk -F: 'BEGIN{OFS=\"-\"} {print \$1,\$2,\$3}' /etc/passwd > /awkfile2.txt"
cat /awkfile2.txt
```

### Task 18: awk - print 1st field for lines containing `nologin`
```bash
sudo sh -c "awk -F: '/nologin/ {print \$1}' /etc/passwd > /awkfile3.txt"
cat /awkfile3.txt
```

## Tools/Commands Used
- `head`, `tail` - viewing beginning/end of files
- `grep` (basic and extended `-E`) - pattern searching
- `awk` - field-based text processing
- `wc -l` - line counting
- `sort` - sorting output

- **OS:** Amazon Linux (EC2 instance)
- **User:** `ec2-user`
- **Access:** via `sudo`
